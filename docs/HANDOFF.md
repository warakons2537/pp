# WL Admin (ปพ.) — สรุปโครงการสำหรับคุยต่อในแชทใหม่

> วิธีใช้: เริ่มแชทใหม่ แนบไฟล์ `school-admin-pp.zip` (โค้ดทั้งหมด) และไฟล์นี้ แล้วบอกว่า
> "นี่คือโครงการ WL Admin ที่ทำต่อจากแชทก่อน อ่าน docs/HANDOFF.md ก่อน แล้วช่วย…"
> อัปเดตล่าสุด: 20 ต.ค. 2569

## 1. แอปนี้คืออะไร

**WL Admin (ปพ.)** — ธุรการชั้นเรียน & ปพ. โรงเรียนบ้านวังลึก (ยุวนาฏชนูทิศ) สพป.สุโขทัย เขต 2
โรงเรียนขยายโอกาส (อนุบาล–ม.3) ระบบธุรการชั้นเรียนกับระบบ ปพ. รวมเป็นแอปเดียว ใช้ฐานข้อมูลร่วมกัน
ครูหลายคนกรอกพร้อมกันได้และเห็นข้อมูลกันทันที (เรียลไทม์) ทุกส่วนพิมพ์เป็นรายงาน A4 ได้

- หน้าเว็บ: ไฟล์ HTML/JS ล้วน ไม่มีขั้นตอน build เผยแพร่ผ่าน **GitHub Pages**
- ฐานข้อมูล: **Supabase** (แผนฟรี) — PostgreSQL + Auth (อีเมล/รหัสผ่าน) + RLS + Realtime
- `js/config.js` ว่าง = **โหมดทดลอง** (ข้อมูลสมมติใน localStorage ของเบราว์เซอร์) ใช้ทดสอบหน้าจอได้โดยไม่ต้องมีฐานข้อมูล
- อยู่ในแผน "Wangluek(Y.N.) Connected" ซึ่งจะรวม WL Admin, WL Scheduler (ตารางสอน), ระบบสอนแทน และแอปวิชาการอื่น ๆ ไว้ใต้ทางเข้าเดียว (ยังไม่ได้ทำ)

## 2. สถานะการติดตั้งจริง

- สร้างโปรเจกต์ Supabase แล้ว ใส่ Project URL + Publishable key ใน `js/config.js` บน GitHub แล้ว
- เคยเจอ "Invalid path specified in request URL" ตอนสมัครคนแรก — แก้ให้แอปตัด `/rest/v1/` ออกจาก URL เองแล้ว
  และเพิ่มข้อความแจ้งเป็นภาษาไทยที่บอก URL ที่ใช้อยู่ **ยังไม่ได้รับยืนยันว่าแก้หายแล้ว**
  (สาเหตุที่น่าจะเป็น: เบราว์เซอร์ยังจำ config.js ตัวเก่า · ถ้ายังไม่หายให้ดู F12 → Network → Request URL)
- คู่มือติดตั้งฉบับเต็ม: `docs/SETUP.md` (และเอกสาร Claude Docs "คู่มือติดตั้งสมุดประจำชั้น")
- **การอัปเดตทุกครั้ง:** อัปโหลดไฟล์ทับใน GitHub **ยกเว้น `js/config.js`** · ถ้า `supabase/schema.sql` เปลี่ยน ให้รันใหม่ใน SQL Editor (รันซ้ำได้ ข้อมูลไม่หาย) · แล้วกด Ctrl+F5
- ยังไม่ได้ทดสอบกับ Supabase จริงหรือ Microsoft Excel จริงในเครื่องของผู้พัฒนา (ทดสอบกับ PostgreSQL ในเครื่อง, โหมดทดลอง และ LibreOffice)

| นักเรียน | นำเข้าจากไฟล์ DMC (ทั้งโรงเรียน สร้างห้องให้เอง) · แก้ไข · วันที่เข้าเรียน · ย้ายออก · เรียงเลขที่ |

| น้ำหนัก-ส่วนสูง | ภาวะโภชนาการตามเกณฑ์กรมอนามัย (ตารางอ้างอิงจากไฟล์ Excel เดิม เปลี่ยนเป็นชุดใหม่ด้วย CSV ได้) |

สิทธิ์: ผู้สมัครคนแรก = ผู้ดูแลระบบ · คนต่อไป "รออนุมัติ" · ครูประจำชั้นแก้ข้อมูลห้องตัวเอง · ครูผู้สอนแก้คะแนนวิชาที่สอน (บังคับด้วย RLS ในฐานข้อมูล)

## 4. งานล่าสุด (ทำในแชทนี้ ตามลำดับ)

1. ระยะ 1–4: DMC, เวลาเรียน, รายงาน A4 → คะแนน/เกรด ปพ.5 → สุขภาพ/คุณลักษณะ/กิจกรรม → พิมพ์ ปพ.6, ปก ปพ.5, ใบรับรอง → ปรับ UI (ธีม "สมุดประจำชั้น")
2. คู่มือติดตั้ง · แก้ปัญหา URL Supabase · เปลี่ยนชื่อ/โลโก้เป็น WL Admin (ปพ.) (`js/brand.js`, `img/`)
3. แบบบันทึกผลสัมฤทธิ์ (ไฟล์ "ผลสัมฤทธิ์" ของ I♥วิชาการ): ส่งออก/นำเข้า ตำแหน่งเซลล์และสูตรเหมือนเดิม (C–AX เก็บ · AY รวม · AZ ปลายภาค · BA รวม · BB เกรด) ตรวจกับไฟล์จริง 5 ไฟล์ตรงทุกคน
4. **แก้บั๊ก "บันทึกแล้วข้อมูลไม่ขึ้น ต้องรีเฟรช"**: `ctx.refresh()` ครั้งที่ 2 เป็นต้นไปเขียนลงสำเนาที่ไม่มีหน้าจอใช้ — แก้แล้ว + โหลดโครงสร้างใหม่อัตโนมัติเมื่อเครื่องอื่นแก้ (realtime) + กันเปิดสอนวิชาซ้ำ
5. **แบบประเมินละเอียด** (จากไฟล์ ม.1–ม.3 ของโรงเรียน):
   - คุณลักษณะ 18 ตัวชี้วัด / 51 พฤติกรรม คะแนน 0–3 · เกณฑ์รายตัวชี้วัดตามไฟล์เดิมทุกแผ่น
   - สมรรถนะ 5 ด้าน × 5 ข้อ คะแนน 1–3 · สรุปผลรายด้าน = ฐานนิยม (เท่ากันเลือกค่าต่ำ)
   - ผลสรุปรายข้อเขียนลง `trait_scores` อัตโนมัติ (ใช้ใน ปพ.6)
   - ส่งออก Excel แผ่นงานครบเหมือนไฟล์เดิม ตรวจกับข้อมูลสมรรถนะจริง ม.1 ตรงทุกช่อง
   - แก้จุดผิดของสูตรเดิม (ช่วงที่ได้ FALSE, ภาพรวม "ผ่าน" ไม่มีทางได้, ตัวเลขตายตัว 248/240/30, หาร 14 แทน 15, นับแถวว่าง) — ผู้ใช้ยังไม่ได้ตอบว่าจะเอาแบบเดิมทุกจุดหรือไม่
6. **เล่ม ปพ. เหมือนไฟล์ต้นฉบับ (ระยะที่ 1: เติมแม่แบบ)** — เมนู พิมพ์ ปพ. → "เล่ม ปพ. (เหมือนไฟล์ต้นฉบับ)"
   - ผู้ดูแลอัปโหลดไฟล์ ปพ.5-6 ของโรงเรียน (.xlsm/.xlsx — ถ้าเป็น .xlsb ให้ Excel "บันทึกเป็น" ก่อน) **ครั้งเดียว** เก็บใน Supabase Storage bucket ส่วนตัว `pp-files` (path `pp/template`) — **ห้ามใส่ไฟล์นี้ใน repo** (โปรแกรมมีลิขสิทธิ์)
   - แอปเติมข้อมูลห้องลงแผ่นงานตามตำแหน่งเซลล์เดิม (รายวิชา ข้อมูลนักเรียน ข้อมูลเพิ่มเติม เวลาเรียน 12 เดือน น้ำหนัก-ส่วนสูง วิชาที่ 1–20 คุณลักษณะ สมรรถนะ กิจกรรม) สูตร/รูปแบบ/พื้นที่พิมพ์เดิมอยู่ครบ
   - เลือกแผ่น เรียงลำดับ ตั้งแนวกระดาษรายแผ่น (จำไว้ในเครื่อง) ค่าเริ่มต้น = "ปก ปพ.5 รายชั้น" ถึง "เกรดร้อยละ" ตามลำดับเดิม ไม่เลือกแผ่นวิชาที่ไม่ได้ใช้
   - PDF: เปิดไฟล์ใน Excel → ส่งออก PDF แบบ "ทั้งเวิร์กบุ๊ก" (แผ่นที่ไม่ได้เลือกถูกซ่อน จึงไม่พิมพ์)
   - ข้อควรรู้: ไม่เขียนเซลล์ที่ไฟล์ล็อกไว้ (เช่น ชื่อโรงเรียนใน "ข้อมูลพื้นฐาน") · เพศเขียนเป็น ช/ญ (สูตรในแม่แบบแปลง "ชาย" เป็นหญิง) · ความเห็นครูประจำชั้นลง ข้อมูลเพิ่มเติม คอลัมน์ AA · สูงสุด 45 คน 20 วิชา
   - โค้ด: `js/xlsx-template.js` (อ่าน/แก้/บันทึก xlsx เดิม), `js/pp-book.js` (แผนที่เซลล์ + รวบรวมข้อมูล), `js/views/pp-book-view.js`
   - ยังไม่ได้ทดสอบกับ Excel จริงและ Supabase จริง (ทดสอบด้วย LibreOffice + โหมดทดลอง ผลเกรด/GPA ตรงกับแอป)
7. **เล่ม ปพ. ระยะที่ 2: ดูตัวอย่าง/พิมพ์/PDF ในแอป ไม่ต้องมี Excel** — ปุ่ม "ดูตัวอย่าง / พิมพ์ / PDF"
   - แอปเปิดไฟล์ต้นฉบับที่เติมข้อมูลแล้ว **คำนวณสูตรของไฟล์เอง** (`js/xl-formula.js`) แล้ว **วาดทุกหน้าแบบที่ Excel พิมพ์** (`js/xl-render.js`)
     ตามพื้นที่พิมพ์ หัวตารางซ้ำ ตัวแบ่งหน้า ย่อ/พอดีหน้า จัดกึ่งกลาง ผสานเซลล์ เส้นขอบ สีพื้น รูปแบบตัวเลข การจัดรูปแบบตามเงื่อนไข รูปภาพ/กล่องข้อความ
   - เลือกแผ่น เรียงลำดับ แนวกระดาษ การย่อ (ตามต้นฉบับ/พอดี 1 หน้า/พอดีความกว้าง/ไม่ย่อ) รายแผ่น · เลือก/ไม่เลือก **รายหน้า** ในตัวอย่าง · พิมพ์หรือบันทึก PDF ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ (A4 ไม่มีขอบ หน้าแนวนอนเป็นกระดาษแนวนอน)
   - แผ่นรายคน (มีชื่อ `No` ประจำแผ่น: ปพ.6, เล่ม ปพ.6, ใบรับรอง) พิมพ์ทุกคนหรือระบุเลขที่ เช่น `1-5, 8` (แทนแมโครของไฟล์ต้นฉบับ)
   - ตรวจกับไฟล์จริง: สูตร 36,322 ช่อง ตรงกับ LibreOffice 97.8% ส่วนที่ต่างเป็นพฤติกรรม Excel ที่ LibreOffice ทำต่าง (วันที่ วว/ดด/ปปปป แบบไทย, อ้างช่องว่าง = 0, MODE กรณีเสมอ, ชื่อที่ LibreOffice แปลงหาย)
   - ความกว้างคอลัมน์คิดแบบจอ 125% (ไฟล์ต้นฉบับจัดหน้าบนจอ 125% — ยืนยันจากค่า scale ที่ Excel บันทึกไว้ เช่น วิชาที่ 1 = 28% ตรงกัน) เปลี่ยนได้ใน "ขั้นสูง"
   - ฟอนต์: ถ้าเครื่องมี TH SarabunPSK ใช้ฟอนต์นั้น ถ้าไม่มีใช้ Sarabun ย่อ 74% (รูปร่างตัวอักษรต่างเล็กน้อย ตำแหน่งตารางเหมือนเดิม)
   - ไฟล์ Excel ที่ส่งออกได้รับแนวกระดาษและการย่อตามที่ตั้งด้วย (`Template.setFit`)

## 7. กติกาสำคัญที่ตกลงกันไว้

- ผลคำนวณต้องตรงกับไฟล์ Excel เดิมของโรงเรียน ถ้าสูตรเดิมผิดให้แก้แล้ว **แจ้งให้ชัด** ว่าต่างตรงไหน
- คะแนนระหว่างภาค = ROUNDDOWN(Σคะแนน ÷ (Σเต็ม ÷ สัดส่วน)) (ตั้งเป็นปัดครึ่งขึ้น/ไม่ปัดได้) · ช่องว่าง = 0 แต่แสดง * ว่ายังไม่ครบ
- ไม่เผยแพร่ข้อมูลนักเรียนจริง: repo บน GitHub เป็น Public มีแต่โค้ด ข้อมูลจริงอยู่ใน Supabase · ไฟล์สำรองมีข้อมูลส่วนบุคคล เก็บในที่ปลอดภัย
- ห้ามใส่ Secret key ในหน้าเว็บ ใช้ Publishable key เท่านั้น
- ส่งไฟล์อัปเดตแบบไม่มี `config.js` เสมอ
