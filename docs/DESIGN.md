## 3. กติกาการคำนวณที่ถอดได้ (ระบบใหม่ต้องให้ผลตรงกับ Excel)

### 3.1 คะแนนและเกรดรายวิชา (ชีต "วิชาที่ n")
- คะแนนระหว่างภาค = `ROUNDDOWN( Σคะแนนดิบ ÷ (Σคะแนนเต็ม ÷ สัดส่วนระหว่างภาค), 0 )` (ค่าตั้งต้นคือ 70)
- คะแนนรวม = คะแนนระหว่างภาค + คะแนนสอบปลายภาค (เต็ม 30)
- ระดับผลการเรียน: <50 → 0 · 50–54 → 1 · 55–59 → 1.5 · 60–64 → 2 · 65–69 → 2.5 · 70–74 → 3 · 75–79 → 3.5 · ≥80 → 4
- ตัวชี้วัดประเมินเป็น ผ/มผ ถ้ามี มผ อย่างน้อย 1 ตัว ผลรวมของวิชาเป็น มผ (นับแยกจากเกรด)

### 3.2 ผลการเรียนเฉลี่ย (ชีต "เกรดรายชั้น")
- GPA = Σ(เกรด × หน่วยกิต) ÷ Σหน่วยกิต โดย**ไม่นับวิชาที่ได้ ร หรือ มส** ทั้งในตัวตั้งและตัวหาร
- ปัดทิ้งให้เหลือทศนิยม 2 ตำแหน่ง และจัดอันดับด้วย RANK เรียงจากมากไปน้อย

### 3.3 คุณลักษณะฯ / อ่าน คิดวิเคราะห์ และเขียน / ค่านิยม 12 / สมรรถนะ 5
- ให้คะแนนรายข้อ 0–3 แล้วสรุปด้วย**ฐานนิยม** ถ้ามีฐานนิยมหลายค่าให้ใช้ค่าที่**สูงสุด** ถ้าไม่มีค่าซ้ำเลยให้ใช้ค่าสูงสุด
- คุณลักษณะ / อ่านคิดวิเคราะห์ / ค่านิยม: 0 = ไม่ผ่าน, 1 = ผ่าน, 2 = ดี, 3 = ดีเยี่ยม
- สมรรถนะ: 0 = ปรับปรุง, 1 = พอใช้, 2 = ดี, 3 = ดีเยี่ยม

### 3.4 เวลาเรียน (ชีตรายเดือน)
- รหัส: 1 = มา, ป = ป่วย, ล = ลา, ข = ขาด (ระบบใหม่เพิ่ม "สาย" ซึ่งนับว่ามา)
- Excel: วันเต็ม = จำนวนวันที่นักเรียนคนนั้นมีการบันทึก · ร้อยละ = วันมา ÷ วันเต็ม × 100
- ระบบใหม่: วันเต็ม = จำนวนวันที่**ห้องนั้น**มีการเช็กชื่อ (ถ้าครูเช็กครบทุกคน ผลจะเท่ากับ Excel)

### 3.5 ภาวะโภชนาการ (ชีตโภชนาการ)
- อายุ = จำนวนเดือนเต็ม นับจากวันเกิดถึงวันชั่ง
- เปิดตารางอ้างอิงด้วยรหัส `เพศ(1 = ชาย, 2 = หญิง) & อายุเดือน` (อายุ 0–227 เดือน หรือประมาณ 19 ปี) และ `เพศ & ส่วนสูง(ซม. ปัดเศษ)` (ชาย 50–180 ซม., หญิง 50–170 ซม.)
- น้ำหนักตามอายุ: > +2SD มากกว่าเกณฑ์ · > +1.5SD ค่อนข้างมาก · ≥ −1.5SD ตามเกณฑ์ · ≥ −2SD ค่อนข้างน้อย · ที่เหลือ น้อยกว่าเกณฑ์
- ส่วนสูงตามอายุ: สูงกว่าเกณฑ์ / ค่อนข้างสูง / ตามเกณฑ์ / ค่อนข้างเตี้ย / เตี้ย (ใช้จุดตัดเดียวกัน)
- น้ำหนักตามส่วนสูง: > +3SD อ้วน · > +2SD เริ่มอ้วน · > +1.5SD ท้วม · ≥ −1.5SD สมส่วน · ≥ −2SD ค่อนข้างผอม · ที่เหลือ ผอม
- ชั่งวัดได้ 4 ครั้งต่อปี

- **ปก ปพ.5 รายชั้น / รายวิชา:** จำนวนนักเรียนต้นภาค/ออก/เข้า/สิ้นภาค, การกระจายเกรด, สรุปการประเมิน และส่วนอนุมัติ (☐ อนุมัติ ☐ ไม่อนุมัติ)
- **ปพ.6 รายบุคคล:** หน้า 1 เป็นผลการเรียน และหน้า 2 เป็นสุขภาพ ความเห็น และคำอธิบาย พิมพ์ทั้งห้องหรือเฉพาะช่วงเลขที่ได้ ทั้งแบบภาคเรียนและทั้งปี
- **ใบรับรองผลการศึกษา:** เลขที่เรียงอัตโนมัติ ข้อความรับรองแก้ได้ และมีช่องติดรูป 3 × 4 ซม.
- **ช่องข้อมูลอิงจากหน้าพิมพ์ในไฟล์ Excel เดิม:** ชื่อ เลขประจำตัว เฉลี่ยในชั้น ร้อยละ ลำดับคะแนนรวม GPA และลำดับ GPA คุณลักษณะ กิจกรรม ลายเซ็น 4 ฝ่าย ภาวะโภชนาการ ความเห็น ส่วนการจัดหน้าออกแบบใหม่ทั้งหมด
- **การนับจำนวนนักเรียน:** ต้นภาค = อยู่ในห้องตั้งแต่วันเปิดภาค · เข้าระหว่างภาค = มีวันที่เข้าเรียนหลังวันเปิดภาค · ออกระหว่างภาค = วันที่ออกอยู่ในภาคเรียน · สิ้นภาค = ต้นภาค + เข้า − ออก
- **GPA ทั้งปี:** คิดจากทุกวิชาของทุกภาคเรียนในปีการศึกษารวมกัน ถ่วงน้ำหนักด้วยหน่วยกิต โดยไม่นับวิชาที่ได้ ร หรือ มส
- **เรื่องที่ยังเปิดอยู่:** ถ้าโรงเรียนต้องการให้หน้าตาเหมือน ปพ.6 ที่ใช้อยู่ทุกช่อง ส่งรูปหรือ PDF ตัวอย่างมาเพื่อปรับให้ตรงได้ ส่วน ปพ.1 (ระเบียนแสดงผลการเรียน) ต้องใช้ผลการเรียนสะสมหลายปีและพิมพ์ลงกระดาษของ สกสค. ซึ่งยังไม่อยู่ในขอบเขตนี้

## 7. เรื่องที่ต้องยืนยันกับฝ่ายวัดผล

1. **การปัดเศษคะแนนระหว่างภาค:** ตอนนี้ระบบตั้งค่าเริ่มต้นเป็นปัดทิ้งเหมือน Excel และเปลี่ยนได้ที่ ตั้งค่าระบบ → โรงเรียน (ปัดทิ้ง / ปัดครึ่งขึ้น / ไม่ปัด) ควรตกลงกันก่อนเริ่มภาคเรียน
2. **ตารางอ้างอิงโภชนาการ:** ตารางในไฟล์ Excel รองรับส่วนสูงชายถึง 180 ซม. แต่หญิงถึงแค่ 170 ซม. ตอนนี้มีนักเรียนหญิงที่สูง 171–172 ซม. แล้ว ซึ่งระบบแปลผลไม่ได้ ควรขอตารางตัวเลขเกณฑ์ฉบับปี 2563 จากศูนย์อนามัยหรือสำนักโภชนาการ แล้วนำเข้าที่ ตั้งค่าระบบ → ตารางโภชนาการ
3. **ฐานนิยมเมื่อมีหลายค่า:** ใช้ค่าสูงสุดตามที่ Excel ทำอยู่หรือไม่
4. **ใครประเมินคุณลักษณะ:** ตอนนี้ให้ครูประจำชั้นเป็นผู้บันทึก (เหมือนไฟล์ Excel) ถ้าต้องการให้ครูผู้สอนทุกวิชาประเมินแล้วสรุปรวม ต้องปรับเพิ่ม
5. **รูปแบบ ปพ.5 / ปพ.6:** ใช้หน้าตาแบบที่พิมพ์อยู่ปัจจุบัน หรือปรับใหม่

## 8. ข้อควรระวัง

- **ลิขสิทธิ์:** ไฟล์ต้นแบบเป็นโปรแกรมเชิงพาณิชย์ ระบบนี้ใช้กติกาการวัดผลตามระเบียบ (ซึ่งเป็นของกระทรวง) แต่ไม่คัดลอกข้อความหรือหน้าตาของโปรแกรมนั้น
- **ข้อมูลส่วนบุคคล (PDPA):** ไฟล์สำรองข้อมูลมีเลขประจำตัวประชาชนและข้อมูลผู้ปกครอง ควรเก็บในที่จำกัดสิทธิ์ และห้ามใส่ Secret key ของ Supabase ในหน้าเว็บ
