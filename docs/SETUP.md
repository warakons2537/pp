# วิธีติดตั้งระบบ (ใช้เวลาประมาณ 30 นาที ไม่มีค่าใช้จ่าย)

มี 3 ส่วน: (1) สร้างฐานข้อมูลบน Supabase (2) ใส่ค่าเชื่อมต่อในแอป (3) นำเว็บขึ้นออนไลน์บน GitHub Pages

---

## ส่วนที่ 1: สร้างฐานข้อมูลบน Supabase

1. ไปที่ https://supabase.com กด **Start your project** แล้วสมัครด้วยบัญชี GitHub (สมัคร GitHub ก่อนที่ https://github.com ถ้ายังไม่มี เพราะต้องใช้ในส่วนที่ 3 อยู่แล้ว)
2. กด **New project**
   - Name: เช่น `school-admin`
   - Database Password: กด Generate แล้ว**จดเก็บไว้ในที่ปลอดภัย**
   - Region: **Southeast Asia (Singapore)** ซึ่งใกล้ไทยที่สุด ระบบจะเร็วกว่า
   - Plan: Free
3. รอประมาณ 2 นาทีจนโปรเจกต์พร้อม
4. เมนูซ้าย **SQL Editor** → **New query** → เปิดไฟล์ `supabase/schema.sql` คัดลอกทั้งหมดมาวาง → กด **Run**
   - ถ้าขึ้น `Success. No rows returned` แปลว่าสำเร็จ
   - ไฟล์นี้รันซ้ำได้ เช่น ตอนอัปเดตระบบในระยะต่อไป
5. เมนู **Authentication** → **Sign In / Providers** → **Email**
   - เปิด Email ไว้
   - **แนะนำให้ปิด "Confirm email"** เพราะอีเมลฟรีของ Supabase ส่งได้แค่ไม่กี่ฉบับต่อชั่วโมง ถ้าครูสมัครพร้อมกันหลายคนจะได้อีเมลไม่ครบ
     ปิดแล้วก็ยังปลอดภัย เพราะครูที่สมัครใหม่จะเห็นข้อมูลก็ต่อเมื่อผู้ดูแลอนุมัติแล้วเท่านั้น
6. เมนู **Project Settings** → **API Keys** แล้วจดค่า 2 ค่า
   - **Project URL** เช่น `https://abcdefghij.supabase.co` (อยู่ในหน้า Data API หรือปุ่ม **Connect** ด้านบน)
   - **Publishable key** ขึ้นต้นด้วย `sb_publishable_`
   - ⚠️ **ห้ามใช้ Secret key** (`sb_secret_...`) ในหน้าเว็บเด็ดขาด เพราะจะข้ามระบบสิทธิ์ทั้งหมด

## ส่วนที่ 2: ใส่ค่าเชื่อมต่อในแอป

เปิดไฟล์ `js/config.js` ด้วยโปรแกรมแก้ข้อความ (Notepad ก็ได้) แล้วใส่ค่า

```js
export const SUPABASE_URL = 'https://abcdefghij.supabase.co';
export const SUPABASE_KEY = 'sb_publishable_xxxxxxxxxxxxxxxx';
```

บันทึกไฟล์ ถ้าเว้นสองค่านี้ว่างไว้ แอปจะเปิดในโหมดทดลอง

## ส่วนที่ 3: นำเว็บขึ้นออนไลน์ (GitHub Pages ฟรี)

1. ที่ https://github.com กด **New repository** ตั้งชื่อ เช่น `school-admin` เลือก **Public** แล้วกด Create
   - โค้ดเปิดเผยได้ เพราะไม่มีข้อมูลนักเรียนอยู่ในโค้ด ข้อมูลทั้งหมดอยู่ใน Supabase ซึ่งมีระบบสิทธิ์ป้องกัน
2. กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ลงไป → **Commit changes**
   - โฟลเดอร์ `.github` เป็นโฟลเดอร์ซ่อน ถ้าลากไม่ขึ้นให้ข้ามไปก่อน (ดูหัวข้อกันฐานข้อมูลถูกพักด้านล่าง)
3. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอ 1–2 นาที จะได้ที่อยู่เว็บ เช่น `https://ชื่อผู้ใช้.github.io/school-admin/`
5. กลับไปที่ Supabase → **Authentication** → **URL Configuration** → ใส่ที่อยู่เว็บนี้ในช่อง **Site URL**

> ถ้าอยากให้ Claude เป็นคนอัปโหลดขึ้น GitHub ให้ บอกได้เลย ผ่านการเชื่อมบัญชี GitHub

## เริ่มใช้งานครั้งแรก

1. เปิดเว็บ → **สมัครใช้งาน** ด้วยอีเมลของคุณ ระบบจะตั้ง**ผู้สมัครคนแรกเป็นผู้ดูแลระบบอัตโนมัติ**
2. **ตั้งค่าระบบ → โรงเรียน:** กรอกชื่อโรงเรียน เขตพื้นที่ ผู้อำนวยการ และหัวหน้าวิชาการ
3. **ตั้งค่าระบบ → ภาคเรียน:** เพิ่มภาคเรียนปัจจุบันพร้อมวันเปิด-ปิดภาค
4. **นักเรียน → นำเข้าจาก DMC:** ใช้ไฟล์ที่ส่งออกจาก DMC ทั้งโรงเรียน ระบบจะสร้างห้องและใส่เลขที่ให้อัตโนมัติ
5. ให้ครูทุกคนสมัครใช้งาน แล้วไปที่ **ตั้งค่าระบบ → ผู้ใช้** เปลี่ยนสิทธิ์จาก "รออนุมัติ" เป็น "ครู"
6. **ตั้งค่าระบบ → ห้องเรียน:** กำหนดครูประจำชั้นของแต่ละห้อง
7. **ตั้งค่าระบบ → รายวิชา:** เพิ่มรายวิชา แล้วกด "เปิดสอนวิชา" เลือกห้องและครูผู้สอน (เลือกได้หลายห้องพร้อมกัน)
8. **ตั้งค่าระบบ → ตารางโภชนาการ:** กด "โหลดตารางจากไฟล์ Excel เดิม" ครั้งเดียว เพื่อให้หน้าน้ำหนัก-ส่วนสูงแปลผลได้

## พิมพ์เอกสาร ปพ.

- เมนู **พิมพ์ ปพ.6 / ปก ปพ.5 / ใบรับรอง** เลือกห้องและชนิดเอกสาร แล้วกด "พิมพ์ / บันทึก PDF"
- ในหน้าต่างพิมพ์ เลือกกระดาษ **A4** ระยะขอบ **ไม่มี (None)** และติ๊ก **กราฟิกพื้นหลัง (Background graphics)**
- นักเรียนที่เข้าเรียนระหว่างภาค ให้กรอก "วันที่เข้าเรียน" ที่หน้า นักเรียน → แก้ไข เพื่อให้ปก ปพ.5 นับจำนวนถูกต้อง ส่วนคนที่ย้ายออก ให้กด "ย้ายออก" ในหน้าเดียวกัน

## กันฐานข้อมูลถูกพักช่วงปิดเทอม

แผนฟรีของ Supabase จะพักโปรเจกต์ถ้าไม่มีการใช้งานประมาณ 7 วัน ข้อมูลไม่หาย แต่ต้องกด **Resume project** ในหน้า Supabase ก่อนใช้งานต่อ
ระบบนี้มีตัวช่วยเรียกฐานข้อมูลทุก 2 วันให้อัตโนมัติ:

1. อัปโหลดไฟล์ `.github/workflows/keepalive.yml` ขึ้น GitHub
   - ถ้าลากโฟลเดอร์ซ่อนไม่ได้ ให้กด **Add file → Create new file** พิมพ์ชื่อ `.github/workflows/keepalive.yml` แล้ววางเนื้อหาไฟล์
2. **Settings → Secrets and variables → Actions → New repository secret** แล้วเพิ่ม 2 ค่า
   - `SUPABASE_URL` = Project URL
   - `SUPABASE_KEY` = Publishable key
3. แท็บ **Actions** → เลือก `keep-supabase-awake` → **Run workflow** เพื่อทดสอบ ถ้าขึ้นเครื่องหมายถูกสีเขียวแปลว่าใช้ได้

หมายเหตุ: GitHub จะหยุดงานอัตโนมัติถ้าโปรเจกต์ไม่มีการแก้ไขนาน 60 วัน และจะส่งอีเมลเตือนก่อน ถ้าได้อีเมลนั้นให้กดเปิดใช้งานต่อ

## สำรองข้อมูล

**ตั้งค่าระบบ → สำรองข้อมูล → ดาวน์โหลดไฟล์สำรอง** จะได้ไฟล์ Excel ที่มีข้อมูลทุกตาราง
ควรทำทุกสัปดาห์ และทุกครั้งก่อนปิดภาคเรียน แล้วเก็บไว้ใน Google Drive ของโรงเรียน

## อัปเดตเป็นเวอร์ชันใหม่

1. รันไฟล์ `supabase/schema.sql` ฉบับใหม่ใน SQL Editor อีกครั้ง ข้อมูลเดิมจะไม่หาย เพราะไฟล์นี้เพิ่มเฉพาะส่วนที่ยังไม่มี
2. อัปโหลดไฟล์ในโฟลเดอร์ `js` และ `css` ขึ้น GitHub ทับของเดิม **แต่อย่าอัปโหลด `js/config.js` ทับ** เพราะไฟล์นั้นมีค่าเชื่อมต่อของโรงเรียนอยู่
3. ครูรีเฟรชหน้าเว็บ (Ctrl + F5)

## เมื่อมีปัญหา

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ขึ้นว่า "ไม่มีสิทธิ์บันทึกข้อมูลส่วนนี้" | ครูคนนั้นยังไม่ได้เป็นครูประจำชั้นของห้องนั้น หรือยังไม่ได้เป็นครูผู้สอนวิชานั้น ให้ผู้ดูแลกำหนดในหน้าตั้งค่า |
| ครูสมัครแล้วเห็นแค่ "รอการอนุมัติ" | ผู้ดูแลต้องเปลี่ยนสิทธิ์ในหน้า ตั้งค่าระบบ → ผู้ใช้ |
| เปิดเว็บแล้วขึ้นว่าเชื่อมต่อฐานข้อมูลไม่ได้ | ตรวจค่าใน `js/config.js` และตรวจว่าโปรเจกต์ Supabase ไม่ได้ถูกพัก (Paused) |
| กรอกคะแนนแล้วขึ้นว่า "เกินคะแนนเต็ม" | ตรวจคะแนนเต็มของช่องนั้นที่แท็บ "ตั้งค่าช่องคะแนน" |
| หน้าน้ำหนัก-ส่วนสูงไม่แปลผล | ผู้ดูแลยังไม่ได้โหลดตาราง (ตั้งค่าระบบ → ตารางโภชนาการ) หรือนักเรียนไม่มีวันเกิด (แก้ที่หน้า "นักเรียน") |
| ผลขึ้นว่า "เกินตารางอ้างอิง" | ส่วนสูงหรืออายุเกินช่วงของตารางที่ใช้อยู่ (ตาราง Excel เดิม: หญิงถึง 170 ซม., ชายถึง 180 ซม.) |
| เกรดมีเครื่องหมาย * | ยังมีช่องคะแนนว่าง ระบบนับช่องว่างเป็น 0 ให้กรอกให้ครบ หรือใส่ 0 ถ้าตั้งใจให้เป็น 0 |
| ข้อมูลไม่อัปเดตทันทีระหว่างเครื่อง | รีเฟรชหน้า 1 ครั้ง และตรวจว่ารันไฟล์ `schema.sql` ครบ (ส่วน Realtime อยู่ท้ายไฟล์) |
