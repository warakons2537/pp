# ระบบธุรการชั้นเรียน + ปพ.

เว็บแอปสำหรับโรงเรียนขยายโอกาส (อ.1 – ม.3) ที่รวมงานธุรการชั้นเรียนกับงาน ปพ. ไว้ในแอปเดียว และใช้ฐานข้อมูลกลางร่วมกัน
ครูทุกคนกรอกข้อมูลพร้อมกันได้ ข้อมูลขึ้นบนหน้าจอของครูคนอื่นทันที

## ใช้งานได้แล้ว

### ระยะที่ 1: ธุรการชั้นเรียน

- **ทะเบียนนักเรียน:** นำเข้าจากไฟล์ DMC ได้ทั้งห้องหรือทั้งโรงเรียนในครั้งเดียว ระบบสร้างห้องให้อัตโนมัติ และนำเข้าซ้ำได้โดยไม่เกิดรายชื่อซ้ำ
- **เช็กชื่อประจำวัน (ครูประจำชั้น):** มีแบบตารางทั้งเดือนเหมือนสมุดเวลาเรียน และแบบรายวันสำหรับมือถือ
- **เช็กชื่อรายคาบ (ครูผู้สอน):** แสดงร้อยละเวลาเรียนของแต่ละวิชา และเตือนเมื่อต่ำกว่า 80% (เสี่ยง มส)
- **รายงาน A4:** เวลาเรียนประจำเดือน (ใช้ส่งผู้บริหารสิ้นเดือน), สรุปเวลาเรียนภาคเรียน, เวลาเรียนรายวิชา และรายชื่อนักเรียน
- **ตั้งค่าระบบ:** ข้อมูลโรงเรียน, ภาคเรียน, ห้องเรียนและครูประจำชั้น, รายวิชาและครูผู้สอน, อนุมัติผู้ใช้ และสำรองข้อมูลเป็นไฟล์ Excel

### ระยะที่ 2: คะแนนรายวิชาและผลการเรียน (ปพ.5)
- **ตั้งค่าช่องคะแนน:** คะแนนเก็บ สอบปลายภาค และตัวชี้วัด ทำได้ 4 แบบ คือ สร้างจากแบบตัวอย่าง, คัดลอกจากห้องอื่น, วางรายการจาก Excel ทีละหลายช่อง หรือเพิ่มทีละช่อง
- **ตารางกรอกคะแนนแบบ Excel:** ใช้ลูกศรหรือ Enter เลื่อนช่อง วางคะแนนจาก Excel ได้ทั้งตาราง บันทึกอัตโนมัติ คะแนนเกินคะแนนเต็มจะถูกปฏิเสธ และครูหลายคนเห็นคะแนนกันทันที
- **คำนวณอัตโนมัติ:** คะแนนระหว่างภาค รวม เกรด ร มส (คิดจากเวลาเรียนรายคาบต่ำกว่า 80% และยกเว้นได้) ตัวชี้วัด ผ/มผ และ GPA กับอันดับ
- **รายงาน A4:** ปพ.5 รายวิชา (พร้อมการกระจายเกรด), ผลการเรียนรายชั้น (GPA และอันดับ) และสรุปผลสัมฤทธิ์
- **แบบบันทึกผลสัมฤทธิ์ (ไฟล์ Excel แบบเดิมของโรงเรียน):** ปุ่ม "ส่งออก Excel" ในหน้าคะแนนรายวิชา ได้ไฟล์ .xlsx แผ่นงาน "ผลสัมฤทธิ์" ตำแหน่งเซลล์และสูตรเหมือนไฟล์เดิม (C–AX คะแนนเก็บ · AY รวม · AZ ปลายภาค · BA รวม · BB เกรด) เลือกส่งออกวิชาเดียวหรือทุกวิชาของห้องในไฟล์เดียว และนำเข้าไฟล์เดิม (.xlsb/.xlsx) กลับเข้าระบบได้ที่แท็บ "ตั้งค่าช่องคะแนน" (ทดสอบด้วย `node tests/achievement.test.mjs`)
- **ตรวจกับไฟล์ Excel จริงแล้ว:** คะแนน เกรด GPA และอันดับ ตรงกับผลใน Excel ทั้ง 2 ภาคเรียน (294 ผลรายวิชา, 21 คน) ดูรายละเอียดใน `docs/DESIGN.md`

### ระยะที่ 3: สุขภาพและการประเมินอื่น
- **น้ำหนัก-ส่วนสูง:** บันทึกได้ 4 ครั้งต่อปี แปลผลทันทีขณะกรอก ทั้งน้ำหนักตามอายุ ส่วนสูงตามอายุ น้ำหนักตามส่วนสูง และ "สูงดีสมส่วน" ตามเกณฑ์กรมอนามัย พร้อมแสดงค่าครั้งก่อนไว้เทียบ
- **ตารางอ้างอิงเปลี่ยนได้:** มาพร้อมตารางจากไฟล์ Excel เดิม และนำเข้าตารางชุดใหม่จากไฟล์ CSV ได้
- **คุณลักษณะอันพึงประสงค์ 8 / อ่าน คิดวิเคราะห์ และเขียน 5 / ค่านิยม 12 / สมรรถนะ 5:** กรอก 0–3 แบบตาราง พิมพ์ตัวเลขแล้วเลื่อนช่องเอง เติมช่องว่างทั้งห้องได้ในครั้งเดียว และสรุปผลด้วยฐานนิยม
- **กิจกรรมพัฒนาผู้เรียน และความเห็นครูประจำชั้น** (ใช้พิมพ์ใน ปพ.6)
- **รายงาน A4:** ภาวะโภชนาการรายห้องพร้อมตารางความชุกและรายชื่อนักเรียนที่ควรดูแล, สรุปคุณลักษณะและกิจกรรม
- **แบบประเมินละเอียด (ตามไฟล์ของโรงเรียน):** คุณลักษณะอันพึงประสงค์ 18 ตัวชี้วัด 51 พฤติกรรม (0–3) และสมรรถนะสำคัญ 5 ด้าน ด้านละ 5 ข้อ (1–3) ที่หน้า "คุณลักษณะ/กิจกรรม" ผลสรุปเขียนลงคุณลักษณะ/สมรรถนะของ ปพ.6 ให้อัตโนมัติ และส่งออกเป็นไฟล์ Excel แผ่นงานครบเหมือนไฟล์เดิม (ทดสอบด้วย `node tests/assess-forms.test.mjs`)
- **เล่ม ปพ. เหมือนไฟล์ต้นฉบับ:** ผู้ดูแลอัปโหลดไฟล์ ปพ.5-6 ของโรงเรียน (.xlsm/.xlsx) ครั้งเดียว เก็บแบบส่วนตัวใน Supabase Storage (ไม่อยู่ใน repo) แอปเติมข้อมูลห้องลงไฟล์นั้นตามตำแหน่งเซลล์เดิม เลือกแผ่นที่จะพิมพ์ เรียงลำดับ และตั้งแนวกระดาษรายแผ่นได้ แล้วกด **ดูตัวอย่าง / พิมพ์ / PDF** เพื่อดูทุกหน้า เลือกพิมพ์รายหน้า และพิมพ์หรือบันทึกเป็น PDF ได้ในแอปเลย (แอปคำนวณสูตรและจัดหน้าตามไฟล์ต้นฉบับเอง ไม่ต้องมี Excel) หรือสร้างไฟล์ Excel ไปพิมพ์ก็ได้ · แผ่นรายคน (ปพ.6, เล่ม ปพ.6, ใบรับรอง) พิมพ์ทุกคนหรือระบุเลขที่ได้ (ทดสอบด้วย `node tests/xlsx-template.test.mjs` และ `node tests/xl-engine.test.mjs`)
- **ตรวจกับไฟล์ Excel จริงแล้ว:** ผลโภชนาการ 81 ครั้งชั่งวัด × 3 ด้าน และสรุปคุณลักษณะ 84 รายการ ตรงกันทั้งหมด

### ระยะที่ 4: พิมพ์เอกสาร ปพ.
- **ปพ.6 รายบุคคล:** พิมพ์ได้ทั้งห้องในครั้งเดียว หรือเลือกช่วงเลขที่ เลือกได้ทั้งภาคเรียนปัจจุบันหรือทั้งปีการศึกษา
  - หน้า 1: ผลการเรียนรายวิชา, เฉลี่ยในชั้น, ร้อยละ, อันดับ, GPA, เวลาเรียน, คุณลักษณะ, กิจกรรม และลายเซ็น
  - หน้า 2: ภาวะการเจริญเติบโต 4 ครั้ง, ความเห็นครู, ช่องความเห็นผู้ปกครอง และคำอธิบายผลการเรียน
- **ปก ปพ.5 รายชั้น:** จำนวนนักเรียนต้นภาค/ออก/เข้า/สิ้นภาค, การกระจายเกรดทุกวิชา, สรุปการประเมิน และส่วนอนุมัติผลการเรียน
- **ปก ปพ.5 รายวิชา:** ข้อมูลรายวิชา ครูผู้สอน จำนวนนักเรียน การกระจายเกรด และส่วนอนุมัติ
- **ใบรับรองผลการศึกษา:** เลขที่ใบรับรองเรียงให้อัตโนมัติ, กำหนดข้อความรับรองและวันที่ออกได้, มีช่องติดรูป และเลือกแสดง GPA ได้
- **ผลการเรียนเฉลี่ยทั้งปี:** รวมทุกวิชาของทั้ง 2 ภาคเรียน พร้อมอันดับ

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `js/config.js` | **ใส่ค่าเชื่อมต่อ Supabase ที่นี่** (ถ้าเว้นว่าง แอปจะเปิดในโหมดทดลอง) |
| `supabase/schema.sql` | โครงสร้างฐานข้อมูลทั้งหมด รวมสิทธิ์การเข้าถึงและระบบเรียลไทม์ |
| `js/views/*.js` | หน้าจอแต่ละหน้า |
| `js/dmc.js` | ตัวอ่านไฟล์ DMC |
| `js/grading.js` | เครื่องคำนวณคะแนน เกรด และ GPA (ทดสอบด้วย `node tests/grading.test.mjs`) |
| `js/assess.js` | ภาวะโภชนาการและสรุปคุณลักษณะ (ทดสอบด้วย `node tests/assess.test.mjs`) |
| `js/xlsx-write.js` | เขียนไฟล์ .xlsx เอง (สูตร รูปแบบเซลล์ ผสานเซลล์ ตั้งค่าหน้ากระดาษ) ไม่ต้องใช้ไลบรารีเพิ่ม |
| `js/achievement.js`, `js/achievement-import.js`, `js/achievement-io.js` | แบบบันทึกผลสัมฤทธิ์: สร้างแผ่นงาน, อ่านไฟล์เดิม, ส่งออก/นำเข้า |
| `js/assess-forms.js`, `js/assess-export.js`, `js/views/assess-detail.js` | แบบประเมินคุณลักษณะ/สมรรถนะรายข้อ: เกณฑ์ คำนวณ ส่งออก Excel และหน้ากรอก |
| `js/xlsx-template.js`, `js/pp-book.js` | เล่ม ปพ.: เปิด/แก้ไฟล์ต้นฉบับ และแผนที่เซลล์ของไฟล์ ปพ.5-6 |
| `js/xl-model.js`, `js/xl-formula.js`, `js/xl-numfmt.js`, `js/xl-render.js` | อ่านไฟล์ Excel คำนวณสูตร จัดรูปแบบตัวเลข และวาดหน้ากระดาษแบบที่ Excel พิมพ์ (ทดสอบด้วย `node tests/xl-engine.test.mjs`) |
| `js/yeardata.js` | รวบรวมข้อมูลทั้งปีสำหรับพิมพ์ ปพ.6 / ปก ปพ.5 / ใบรับรอง (ทดสอบด้วย `node tests/print.test.mjs`) |
| `js/data/growth-excel.js` | ตารางอ้างอิงการเจริญเติบโตจากไฟล์ Excel เดิม |
| `docs/SETUP.md` | วิธีติดตั้งทีละขั้น |
| `docs/DESIGN.md` | เอกสารออกแบบระบบ: ถอดจากไฟล์ Excel เดิม, กติกาการคำนวณ, แผนการพัฒนาระยะต่อไป |
| `.github/workflows/keepalive.yml` | กันฐานข้อมูลถูกพักช่วงปิดเทอม |
